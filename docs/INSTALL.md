# Установка APK: если пишет «пакет недействителен»

## 1. Сначала проверьте файл — он мог побиться при передаче

Оригинал:

| | |
|---|---|
| Размер | **3 321 478 байт** (3,17 МБ) |
| SHA-256 | `68299B0015D24898E08A097528924C6750AFF10A2C607094FAFC7AA9BFCC6939` |

**Windows:**
```powershell
certutil -hashfile "TitoV3DCalc-6.1.0.apk" SHA256
```
Должен совпасть с хешем выше.

**Android** (в Termux или через приложение-хэшер): размер должен быть ровно
3 321 478 байт. Если меньше — файл обрезан при скачивании.

Чистая копия без OneDrive: `D:\open code\dist\TitoV3DCalc-6.1.0.apk`.

## 2. Как переносить, чтобы не побить

| Способ | Годится? |
|---|---|
| USB-кабель (режим передачи файлов) | ✅ лучший вариант |
| Telegram «Избранное» → «Сохранить в загрузки» | ✅ |
| Google Drive → «Скачать» (не «Открыть») | ✅ |
| OneDrive на телефоне → «Скачать» | ✅ но проверьте размер |
| Почта / WhatsApp | ⚠️ могут изменить файл |
| Открыть прямо из облака | ❌ может скачаться не полностью |

## 3. Проверьте телефон

Приложение требует **Android 7.0 (API 24) и новее**.

```powershell
# с подключённым по USB телефоном (отладка по USB включена)
adb shell getprop ro.build.version.release
adb install -r "D:\open code\dist\TitoV3DCalc-6.1.0.apk"
```
`adb install` покажет точную причину, если дело не в файле.

Посмотреть версию без ADB: «Настройки» → «О телефоне» → «Версия Android».

## 4. Частые причины и что делать

| Причина | Решение |
|---|---|
| Файл обрезан при скачивании | сверить размер/хеш, скачать заново по кабелю |
| Уже установлена версия с другой подписью | удалить старое приложение, установить заново |
| Запрещена установка из этого источника | «Настройки» → «Приложения» → «Специальный доступ» → «Установка неизвестных приложений» → разрешить файловому менеджеру/Telegram |
| MIUI / HyperOS блокирует | отключить «Оптимизацию MIUI» на время установки или ставить через «Проводник» |
| Мало места | освободить ~50 МБ |
| Android 6 и ниже | не поддерживается (minSdk 24); нужна сборка под старую версию |
| Антивирус/корпоративный профиль | отключить проверку установки |

## 5. Если ничего не помогло

Скажите модель телефона и версию Android — соберу вариант с пониженным `minSdk`
или подпишу иначе. Также можно поставить через ADB: он выдаёт точный код ошибки
(`INSTALL_PARSE_FAILED_*`), по нему сразу видно причину.
