## 3. Найденные проблемы и исправления

| ID | Важность | Проблема | Исправление |
|---|---|---|---|
| N1 | **Высокая** | В Android WebView скачивание файла через `Blob` + `<a download>` **не работает** — экспорт JSON/CSV молча ничего не делал | Добавлен нативный путь: `Filesystem.writeFile` в кэш + системное «Поделиться». Если плагин недоступен — окно с текстом файла и кнопкой «Скопировать». Проверено: fallback открывает валидный JSON (5 742 символа) |
| N2 | Средняя | `window.print()` в Android WebView не вызывается | Задокументировано как ограничение; для PDF — экспорт. На Windows печать работает через WebView2 |
| N3 | Средняя | При сборке файл `index.html` был перекодирован в mojibake (PowerShell `Get-Content`/`Set-Content` прочитал UTF-8 как ANSI) | Откат из резервной копии и повторное применение правок; в `BUILD.md` добавлено правило: править только UTF-8-инструментами, перед сборкой сверять SHA-256 |
| N4 | Низкая | Портативный exe назывался `tito-win.exe` | Скопирован как `TitoV3D Calc 6.0 (portable).exe` |
| N5 | Низкая | Диалог импорта не показывал, что база будет дополнена каталогом | Показывает «+N из каталога» / «+N из стандартных» (v5.1) |

### Что стоит усилить перед публикацией

1. **CSP в Tauri.** Сейчас `csp: null`. Контент только локальный, но для продакшена
   лучше задать `default-src 'self'; script-src 'self' 'unsafe-inline'` (скрипт и
   стили встроены в HTML, поэтому `unsafe-inline` нужен).
2. **Хранение пароля от keystore.** Сейчас он лежит рядом в `keystore-password.txt` —
   перенесите в менеджер паролей и сделайте резервную копию `.jks` в двух местах.
3. **Play App Signing** при загрузке в Google Play.
4. **Кнопка «Назад»** на Android сейчас закрывает приложение с любой вкладки;
   можно добавить обработчик (сворачивание вместо выхода) — 15 минут работы.

## 5. Ограничения версии 6.0

- Данные хранятся в `localStorage` WebView. Очистка данных приложения их удалит —
  делайте экспорт JSON как резервную копию.
- Android: печать недоступна (только экспорт файла).
- Windows: неподписанный exe вызывает предупреждение SmartScreen.
- Автообновления нет: новая версия ставится вручную поверх старой
  (APK с тем же ключом, exe — установщиком).
- Tauri-приложение не проверялось на Windows 10 (только Windows 11 26100).
