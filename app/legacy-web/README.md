# Калькулятор стоимости 3D-печати

Один файл `index.html` — без установки, интернета и зависимостей. Работает в любом
браузере на Windows, Android, macOS, Linux. Данные сохраняются локально в браузере.

## Как открыть

### Windows
1. Двойной клик по `index.html` **или** по `Открыть калькулятор.bat`.
2. Чтобы был быстрый доступ: правый клик по `index.html` → «Отправить» → «Рабочий стол
   (создать ярлык)», затем закрепить ярлык на панели задач или в меню «Пуск».
3. Печать или сохранение в PDF — кнопка «Печать / PDF» (Ctrl+P).

### Android
1. Перекинуть `index.html` на телефон любым способом: Telegram «Избранное»,
   Google Drive, USB-кабель, почта.
2. Открыть файл через файловый менеджер → «Открыть с помощью» → Chrome.
3. Добавить на главный экран: в Chrome меню ⋮ → «Добавить на главный экран».
   Дальше калькулятор открывается как обычное приложение, интернет не нужен.

> Если файл открылся «как текст» — значит выбран текстовый редактор. Нужен именно браузер.

## Что считается

| Строка | Формула |
|---|---|
| Материал | `масса/1000 × цена_за_кг × (1 + отходы%)` |
| Электричество | `Вт/1000 × часы × тариф` |
| Амортизация | `цена_принтера / ресурс_ч × часы` |
| Обслуживание | `₽/ч × часы` |
| Труд | `минуты/60 × ставка × кол-во` |
| Риск брака | `% × прямые затраты` |
| **Себестоимость партии** | сумма всех строк |
| Наценка | `себестоимость × наценка%` |
| Цена | `(себестоимость + наценка) / (1 − комиссия% − налог%)`, округление вверх |
| Чистая прибыль | `выручка − себестоимость − комиссия − налог` |

Комиссия площадки и налог считаются **от цены продажи**, поэтому не «съедают» прибыль —
цена автоматически поднимается так, чтобы после вычетов осталась заданная наценка.

## Поля и значения по умолчанию

- Деталей в печати: 1 (масса и время — на всю партию, труд — на 1 деталь)
- Масса материала: 50 г (модель + поддержки + брайм)
- Время печати: 4 ч 0 мин
- Материал: PLA 1300 ₽/кг, отходы 5 %
- Мощность принтера: 120 Вт, тариф 5,5 ₽/кВт·ч
- Принтер: 35 000 ₽, ресурс 5000 ч, обслуживание 2 ₽/ч
- Труд: 15 мин на деталь, 600 ₽/ч
- Расходники: 10 ₽, упаковка: 15 ₽
- Брак: 5 %, наценка: 40 %, комиссия и налог: 0 %
- Округление цены: до 10 ₽
